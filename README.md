## Мониторинг свободных мест в поликлиниках Санкт-Петербурга

Этот проект представляет собой Telegram-бота для мониторинга свободных мест в поликлиниках Санкт-Петербурга через API "Горздрав". Бот уведомляет пользователей о появлении свободных мест и позволяет управлять настройками мониторинга через удобное меню.

### Возможности

-   Мониторинг доступных мест по заданному ID.
-   Уведомления в Telegram о появлении свободных мест.
-   Настройка интервала проверки.
-   Поддержка прокси-серверов.
-   Управление мониторингом через Telegram-бота (запуск, остановка, статус).
-   Логирование команд пользователей и ответов API.

### Установка

1.  **Клонируйте репозиторий (если вы уже создали его на GitHub и клонировали):**

    ```bash
    git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
    cd parser_spb
    ```

    *Если вы еще не создали репозиторий и просто хотите начать работу с проектом, пропустите этот шаг и продолжайте со следующего.*

2.  **Создайте виртуальное окружение (рекомендуется):**

    ```bash
    python3 -m venv .venv
    ```

3.  **Активируйте виртуальное окружение:**

    -   Для macOS/Linux:
        ```bash
        source .venv/bin/activate
        ```
    -   Для Windows:
        ```bash
        .venv\Scripts\activate
        ```

4.  **Установите зависимости:**

    ```bash
    pip install -r requirements.txt
    ```

### Настройка

1.  **Создайте файл `config.json`** в корневой директории проекта со следующим содержимым:

    ```json
    {
        "telegram_bot_token": "ВАШ_ТОКЕН_БОТА",
        "telegram_user_id": ["ВАШ_ID_ПОЛЬЗОВАТЕЛЯ_TELEGRAM"],
        "search_id": "ID_ПОИСКА_ПОЛИКЛИНИКИ",
        "check_interval": 60,
        "use_proxy": false,
        "proxy": "ВАШ_ПРОКСИ",
        "proxy_user": "ПОЛЬЗОВАТЕЛЬ_ПРОКСИ",
        "proxy_password": "ПАРОЛЬ_ПРОКСИ",
        "notify_on_change": true,
        "monitoring": false
    }
    ```

    -   `telegram_bot_token`: Токен вашего Telegram-бота, полученный от BotFather.
    -   `telegram_user_id`: Список ID пользователей Telegram, которым разрешено взаимодействовать с ботом. (Можно получить свой ID, написав боту @userinfobot).
    -   `search_id`: ID поликлиники или специалиста для поиска свободных мест. Этот ID можно найти, анализируя сетевые запросы на сайте gorzdrav.spb.ru.
    -   `check_interval`: Интервал проверки в секундах (например, 60 для 1 минуты).
    -   `use_proxy`: `true`, если вы хотите использовать прокси, иначе `false`.
    -   `proxy`, `proxy_user`, `proxy_password`: Данные для прокси-сервера (если `use_proxy` установлен в `true`).
    -   `notify_on_change`: `true`, если вы хотите получать уведомления только при изменении количества свободных мест, иначе `false`.
    -   `monitoring`: `true`, если мониторинг должен быть активен при запуске, иначе `false`.

### Запуск бота

После настройки `config.json` вы можете запустить бота:

```bash
python3 bot.py
```

### Структура проекта

-   `main.py`: Основной скрипт для мониторинга API "Горздрав".
-   `bot.py`: Реализация Telegram-бота для взаимодействия с пользователем.
-   `page.py`: Класс для работы с API "Горздрав" (получение данных о свободных местах).
-   `logger.py`: Модуль для логирования действий бота и API-запросов.
-   `config.json`: Файл конфигурации для настроек бота и мониторинга.
-   `requirements.txt`: Список зависимостей Python.
-   `README.md`: Этот файл с описанием проекта.
